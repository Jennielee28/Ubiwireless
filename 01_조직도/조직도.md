# 조직도

## 1. 전체 구조
(예시) 대표 → 영업팀(2명) / 관리팀(2명) / 기술팀(3명)

```
대표
├─ 영업팀
│  ├─ 팀장
│  └─ 직원A
├─ 관리팀 (회계·인사·총무)
│  └─ 직원B
└─ 기술팀
   └─ 직원C
```

## 2. 구성원 목록

| 부서 | 직책/호칭 | 주요 역할 (한 줄) | 주로 쓰는 프로그램 |
|---|---|---|---|
| 예) 관리팀 | 대리 | 세금계산서 발행, 거래처 관리 | 엑셀, 홈택스, 더존 |
|  |  |  |  |
|  |  |  |  |
