## 현재 파악된 기본 정보
- 회사 규모: 10명 이하
- 사업 분야: LTE 라우터 개발·제조·유통, 통합관제, 통합관리·유지관리 (자체 관제시스템 보유)
- 신규 사업: 출퇴근 근태단말기 렌트 (누적 약 3,200대)
- 사용 도구: 엑셀/한글, 구글 워크스페이스(구글 시트), MS 365, **이카운트 ERP**
- 예산 방향: 최소 비용 (무료·저가 도구 우선)
- 1순위 과제: 렌트 세금계산서 발행 + 입금 확인
