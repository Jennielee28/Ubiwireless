# 자동화 요청

자동화하고 싶은 일을 **말하듯이 자세하게** 적어주세요. 항목마다 아래 질문에 답하면 됩니다.

1. 지금은 어떻게 하나요? (순서대로)
2. 누가, 얼마나 자주, 얼마나 걸리나요?
3. 무엇이 가장 불편한가요?
4. 자동화되면 어떻게 되길 바라나요?
5. 사람이 꼭 확인해야 하는 단계가 있나요?
6. 관련 파일·양식 예시가 있나요? (개인정보 지우고 첨부)

## 요청 1: 근태단말기 렌트 정산 (세금계산서 발행 + 입금 확인) ⭐ 1순위

- **현황**: 누적 렌트 약 3,200대
- **불편한 점**
  - 세금계산서 발행일이 불규칙함
  - 입금 여부를 매번 은행 계좌에서 직접 확인해야 함
- **사용 도구**: 이카운트, 구글 시트
- **거래처 수**: 1,000곳 이상 (거래처당 평균 1~3대)
- **발행일이 불규칙한 이유**: 계약일이 거래처마다 다름 + 거래처별 요청(묶음·선불 등)
- **렌트 현황 관리 위치**: 구글 시트, 이카운트, 관제시스템, 엑셀에 **흩어져 있음**
- **수납 방식**: 거래처가 회사 통장으로 직접 계좌이체

### 1차 진단 (Claude)
1. 렌트 정보가 4곳에 나뉘어 있어 "누가 몇 대, 언제 청구" 기준이 하나가 아님 → **렌트 원장 하나로 통합** 필요
2. 1,000곳 넘는 거래처의 입금을 입금자명으로 맞추는 방식은 사람이 할 수밖에 없는 구조 → **거래처별 가상계좌** 또는 **CMS 자동이체** 전환 검토
3. 계약일마다 발행 → 매일 발행 업무 발생 → **청구일 통일(예: 매월 1회) + 일괄 자동 발행** 검토
4. 미납 거래처 자동 안내(카카오 알림톡/문자) 추가 검토

- **추가 확인 필요** (진행 중): 담당자·소요 시간, 단가, 선불/후불, 청구일 통일 가능 여부
