# 자동화 요청

---

## 요청 1: (업무 이름)

1. **지금은 어떻게 하나요?** (순서대로)
   - 예) 메일로 주문서가 온다 → 엑셀에 옮겨 적는다 → ERP에 다시 입력한다 → 거래처에 확인 메일을 보낸다
2. **누가, 얼마나 자주, 얼마나 걸리나요?**
3. **무엇이 가장 불편한가요?** (실수, 시간, 중복 입력 등)
4. **자동화되면 어떻게 되길 바라나요?**
5. **사람이 꼭 확인해야 하는 단계가 있나요?** (예: 금액 승인)
6. **관련 파일·양식 예시가 있나요?** (개인정보 지우고 첨부)
