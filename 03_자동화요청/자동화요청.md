# 자동화 요청

자동화하고 싶은 일을 **말하듯이 자세하게** 적어주세요. 항목마다 아래 질문에 답하면 됩니다.

1. 지금은 어떻게 하나요? (순서대로)
2. 누가, 얼마나 자주, 얼마나 걸리나요?
3. 무엇이 가장 불편한가요?
4. 자동화되면 어떻게 되길 바라나요?
5. 사람이 꼭 확인해야 하는 단계가 있나요?
6. 관련 파일·양식 예시가 있나요? (개인정보 지우고 첨부)

## 요청 1: 근태단말기 렌트 정산 (세금계산서 발행 + 입금 확인) ⭐ 1순위

- **현황**: 누적 렌트 약 3,200대
- **불편한 점**
  - 세금계산서 발행일이 불규칙함
  - 입금 여부를 매번 은행 계좌에서 직접 확인해야 함
- **사용 도구**: 이카운트, 구글 시트
- **거래처 수**: 1,000곳 이상 (거래처당 평균 1~3대)
- **발행일이 불규칙한 이유**: 계약일이 거래처마다 다름 + 거래처별 요청(묶음·선불 등)
- **렌트 현황 관리 위치**: 구글 시트, 이카운트, 관제시스템, 엑셀에 **흩어져 있음**
- **수납 방식**: 계좌이체 + **CMS 자동이체 (이미 사용 중)** — 두 방식 혼용

### 1차 진단 (Claude)
1. 렌트 정보가 4곳에 나뉘어 있어 "누가 몇 대, 언제 청구" 기준이 하나가 아님 → **렌트 원장 하나로 통합** 필요
2. 1,000곳 넘는 거래처의 입금을 입금자명으로 맞추는 방식은 사람이 할 수밖에 없는 구조 → **거래처별 가상계좌** 또는 **CMS 자동이체** 전환 검토
3. 계약일마다 발행 → 매일 발행 업무 발생 → **청구일 통일(예: 매월 1회) + 일괄 자동 발행** 검토
4. 미납 거래처 자동 안내(카카오 알림톡/문자) 추가 검토

- **월 소요 시간**: 20시간 미만
- **청구일 통일**: 신규 계약부터 가능
- **세금계산서 발행 도구**: 이카운트
- **입금 방식 변경**: 미정 → 아래 비교표 검토 중

### 입금 방식 비교 (거래처 1,000곳 기준, 비용은 대략치·업체 견적 확인 필요)

| 방식 | 입금 확인 자동화 | 미납 감소 | 거래처 불편 | 월 비용(추정) |
|---|---|---|---|---|
| A. 현행 계좌이체 + 자동 대조 | 중 (이름·금액으로 70~90% 자동, 나머지 수동) | 낮음 | 없음 | 낮음 (계좌조회 서비스 월 수만 원) |
| B. 거래처별 가상계좌 | 상 (거의 100% 자동) | 중 | 계좌 안내 1회 | 중 (건당 수수료, 견적 필요) |
| C. CMS 자동이체 | 상 | 상 (매달 자동 출금) | 출금 동의서 필요 | 약 20~25만 원 (건당 200~250원) |

**Claude 권장** (CMS 이미 사용 중 반영): 신규 계약은 CMS를 기본으로 → 계좌이체 거래처는 A(자동 대조)로 처리 → 점진적으로 CMS 전환 유도
- CMS 비율: 절반 미만 (계좌이체가 더 많음)
- CMS 업체: 확인 필요
- CMS 출금 결과 확인: CMS 사이트에 로그인해 **눈으로 확인** → 결과 파일 자동 반영 + 출금 실패 거래처 자동 알림 대상
- 추가 확인: CMS 업체명, 출금 실패 시 처리 방법
